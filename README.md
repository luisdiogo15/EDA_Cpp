# EDA_Cpp
Projeto da UC de Estruturas de Dados e Algoritmos em C++

Objetivo: 

Desenvolvimento de um programa em C++ que simule o funcionamento do “EDA FC”. O sistema deverá gerir múltiplas listas de jogadores,
implementar regras de restrição e realizar movimentações frequentes entre listas, garantindo sempre a reorganização adequada dos arrays dinâmicos.


Dar run no código:
cd src
g++ main.cpp jogo.cpp util.cpp inic.cpp gestao.cpp jornada.cpp memoria.cpp ficheiros.cpp -o main
./main
